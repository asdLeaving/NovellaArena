# NovellaArena

一个可以直接托管在 GitHub Pages 的中文小说竞技场。所有内容都在仓库里，站点在浏览器中运行。

## 预览与编辑

在 Windows 双击 `打开网页.bat`。其他系统可以在仓库根目录运行 `python3 tools/serve.py --open`。预览地址与文件夹绑定，可分别打开不同分支。浏览器进入休眠或刷新后，阅读页会尝试恢复到原段落。

| 想改什么 | 从哪里改 |
| --- | --- |
| 正文、标题、章节 | 编辑 `texts/` 下对应的 UTF-8 文本。保留原文件名可以继续使用已有阅读链接。 |
| 题目提示词、参考作品 | 编辑 `prompts/` 下对应的文本。形如 `（《书名》）` 的首行可在评级表中显示参考作品。 |
| 评级、模型列、默认显示的版本 | 编辑 `data/catalog.json`。同题同模型优先显示最高评级，同级优先显示带有 `"preferred": true` 的版本，再按生成时间选取。 |
| 封面、代表作、主观评语 | 封面放在 `assets/covers/`，文件名与正文同名，更换图片扩展名即可。首页代表作的顺序和评语在 `index.html`。 |

## 导入文稿

从首页进入「导入文稿」，拖入或选择 `题目_模型_yymmddhhmm.txt`，再选择评级、harness 和 effort。可以一起填写提示词，也可以单独调整题目的开放度。

- **加入网页**会让你选择包含 `index.html` 和 `data/catalog.json` 的站点文件夹。重复导入同名文稿会更新正文，保留未调整的评级和其他目录字段。
- **下载导入包**会生成带有 `texts/`、`data/` 以及可选 `prompts/` 的 ZIP。解压到与当前页面目录版本一致的仓库。包里的 `catalog.json` 是完整快照，若本地还有其他编辑，先从该文件夹打开预览并重新导出。

## 上传

双击 `推送更新.bat`。脚本会检查目录引用，更新标题、参考作品、封面索引和静态资源版本，再提交到当前分支并推送到 `origin` 上的同名分支。Git 可使用已有凭据或 GitHub CLI 登录。

要在线上启用某一版，把它合入该仓库用于 GitHub Pages 的发布分支，或让 Pages 使用该分支的根目录。手工用 Git 发布时，可以先在 PowerShell 中运行 `./tools/check_catalog.ps1` 和 `./tools/update_asset_versions.ps1`，将生成的索引与正文一起提交。
